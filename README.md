# Android App Store — учебный проект

> **Дисклеймер:** Этот проект создан в рамках курса от VKEducation "Основы Android-разработки от RuStore". Идея приложения и дизайн принадлежат RuStore. Данный репозиторий — моя учебная реализация этих заданий.

---

## О проекте

Учебный клон мобильного магазина приложений. Приложение отображает каталог приложений, полученных с сервера, и позволяет просматривать подробную карточку каждого приложения. Данные кешируются локально в базе данных Room, а понравившиеся приложения можно добавлять в вишлист.

---

## Экраны

### Список приложений
- Загружает каталог приложений с сервера `http://185.103.109.134/catalog`
- Отображает иконку, название, описание и категорию каждого приложения
- Поддерживает состояния: загрузка, контент, ошибка

### Карточка приложения
- Открывается при нажатии на элемент списка
- Загружает подробные данные по `id` приложения: название, разработчик, категория, возрастной рейтинг, размер, описание, скриншоты
- Первый запрос идёт в сеть — результат сохраняется в локальную БД. При повторном открытии данные берутся из кеша
- Кнопка вишлиста (♡ / ♥) — добавляет или убирает приложение из избранного. Состояние хранится в БД и мгновенно отражается в UI через Flow

## Архитектура

Проект построен по принципу **Clean Architecture** и разделён на три слоя:

```
presentation/   — Compose UI, ViewModel, State/Event
domain/         — бизнес-логика, модели, интерфейсы репозиториев, UseCase-ы
data/           — реализации репозиториев, Retrofit DTO, Room Entity, маппинг

```

---

## Unit-тесты

Проект покрыт unit-тестами в трёх категориях:

- **Маппер-тесты** — `AppListMapperTest`, `AppDetailsMapperTest`, `AppDetailsEntityMapperTest`
- **Repository-тесты** — `AppListRepositoryImplTest`, `AppDetailsRepositoryImplTest`
- **UseCase-тесты** — `GetAppListUseCaseTest`, `GetAppDetailsUseCaseTest`

Тесты используют fake-реализации зависимостей.

## Запуск проекта

1. Клонировать репозиторий
2. Открыть в Android Studio Hedgehog или новее
3. Убедиться, что в `AndroidManifest.xml` есть разрешение на интернет и флаг `usesCleartextTraffic`:
   ```xml
   <uses-permission android:name="android.permission.INTERNET" />
   <application android:usesCleartextTraffic="true" ... />
   ```
4. Запустить на эмуляторе или физическом устройстве (API 26+)

## Пройденные темы курса

В рамках курса были реализованы следующие практические задания:

- Создание UI: Jetpack Compose, Coil
- Clean architecture + MVVP
- Работа с сетью: интеграция Retrofit, GET-запросы к API каталога
- Работа с базами данных: Room, DAO, TypeConverter, кеширование данных
- Асинхронность и корутины: suspend-функции, `viewModelScope`, `Dispatchers.IO`
- Подписка на обновление данных: Kotlin Flow, `observeAppDetails`, автообновление UI
- Unit-тестирование: тесты на репозитории, маппер и UseCase
- Современные подходы к разработке: декомпозиция MVP на эпики и задачи
